LatentForge

An Interactive Laboratory for Recurrent Latent Reasoning

What happens when we give a model more time to think
without giving it more tokens to think with?

A deterministic local substrate refines a hidden numerical state instead of writing out intermediate reasoning text. You choose how many times it updates that state, then check its answer against an independently computed truth — no hidden text, no fabricated result.

Run the experiment ↓ Flagship result

FALSIFIABLE CLAIM

A model can perform repeated computation by refining a hidden state instead of verbalizing every intermediate step. This laboratory demonstrates the mechanism using a tiny deterministic local substrate; it does not establish that latent reasoning is universally better or that more computation always improves answers.

Does more latent computation help a trained model reach problem lengths it never saw in training?

A real GRU-based recurrent model (not an untrained fixed-seed toy) is trained on short move sequences (length 2–8) and evaluated on much longer, held-out sequences (length 12–24) it never saw during training. The trained weights never change below — only the number of extra "thinking" steps applied at inference time does.

    07 / RESEARCH LINEAGE
    Research belongs beside the experiment.
    LatentForge separates what papers report from what this local laboratory actually executes.
    
          
    HRM-inspired mode
    
          
    PUBLISHED
    Coupled two-level recurrence
    Wang et al. describe coupled high- and low-level recurrent modules updating at different cadences, with output read from the high-level state.
    LIVE LOCAL
    A simplified H/L recurrence
    This lab runs a deterministic, untrained local H/L recurrence and returns both numerical trajectories.
    SIMPLIFIED
    Not a paper reproduction
    No published training, deep supervision, gradient approximation, adaptive computation, datasets, or benchmarks are reproduced here.
    NOT CLAIMED
    Not HRM itself
    This does not establish HRM superiority, benchmark performance, efficiency, or general accuracy improvement.
    
          
    BDH-CQ-inspired mode
    
          
    PUBLISHED
    Recurrent memory, then latent workspace
    Engdahl et al. describe demonstrations updating S, a query-conditioned H₀, iterative H computation, and final-state decoding.
    LIVE LOCAL
    One inspectable simplification
    This lab runs deterministic CPU updates for S and H and returns their numerical trajectories, prediction, and independent truth.
    SIMPLIFIED
    Not a paper reproduction
    No published training, hidden dimensions, proprietary rules, ARC evaluation, benchmark results, ranking, or efficiency claim is reproduced here.
    NOT CLAIMED
    More state is not a guarantee
    A small untrained local result cannot establish superiority, general accuracy, cost, token savings, or human-like reasoning.
