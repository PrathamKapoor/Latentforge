FlagshipA trained model, tested on lengths it never saw

What happens when a model gets more time to think without more tokens to think with?

LatentForge is a local laboratory for recurrent latent reasoning. A model refines a hidden numerical state instead of writing out intermediate text. You choose how many times it updates, inspect every state, and check the answer against an independently computed truth.

How it works

One recurrence. A budget you control.

Every experiment follows the same five steps, from a question to an independently checked answer.

  1. 01

    Learn

    Start with a guided lesson: one question, one live preset, one stated limitation.

    Guided lesson
  2. 02

    Configure

    Pick a backend, a bounded task and a computation budget of 1, 2, 4 or 8 updates.

    Workspace
  3. 03

    Think in latent space

    The same recurrent transition refines a hidden state h₀ → hₙ. No reasoning tokens are generated.

    The fixed rule
  4. 04

    Inspect

    Scrub every returned state: signed vectors, a heatmap and every dimension's value.

    State inspector
  5. 05

    Compare

    Check the prediction against an independent solver, then sweep budgets side by side.

    Truth vs estimate

        HRM-inspired hierarchical recurrence

        A live, local, untrained educational implementation inspired by HRM's update cadence. It is not a reproduction of HRM.

        • The low-level state updates every step
        • The high-level state updates after every two low steps
        • The output head reads the high-level state

        04Research lineage

        Research belongs beside the experiment.

        LatentForge separates what papers report from what this local laboratory actually executes.

        PublishedLive local

        HRM-inspired mode

        Wang et al. describe coupled high- and low-level recurrent modules that update at different cadences. This lab runs a deterministic, untrained local H/L recurrence and returns both numerical trajectories.

        Published vs implemented
        PublishedLive local

        BDH-CQ-inspired mode

        Engdahl et al. describe demonstrations updating S, a query-conditioned H₀, then iterative H computation. This lab runs deterministic CPU updates for S and H and returns both trajectories.

        Published vs implemented
        Reproducible

        Flagship pipeline

        Training, evaluation and the results file are all in the repository. The charts read the same JSON a reviewer regenerates with one command.

        Claim audit

        What is running, and what is not claimed.

        Live now

        What is actually running

        • Recurrent latent-state execution (persistent local worker)
        • Reasoning-budget manipulation (1, 2, 4, 8)
        • State trajectory inspection
        • Truth/reference comparison
        • HRM-inspired hierarchical recurrence
        • BDH-CQ-inspired recurrent memory
        • Local seed characterization (not a benchmark)
        • Deterministic reproducibility, same seed → same result
        Not claimed

        What this does not prove

        • Latent reasoning is universally superior to explicit chain-of-thought
        • More recurrent steps always improve accuracy
        • Latent states correspond to human-readable thoughts
        • The HRM-inspired or BDH-CQ-inspired modes reproduce those papers
        • Latent computation is cheaper than verbal reasoning
        • This toy substrate represents frontier reasoning systems

        Give the model more steps. Watch what changes.
